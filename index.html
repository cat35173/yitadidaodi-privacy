隐私政策

应用名称：一塌到底（Android 版）· 版本 1.2（versionCode 2）
开发者：赵柏铮　·　包名：com.yitadidaodi.ta
生效日期：2026 年 11 月 24 日　·　最近更新：2026 年 11 月 24 日

一句话说清：这个游戏不收集你的任何个人信息。不申请任何权限，不联网，没有账号，没有广告 SDK。你的游戏进度只存在你自己的手机里。

一、我们是谁

应用名称一塌到底 开发者赵柏铮（个人开发者） 软件形态Android 应用（APK），版本 1.2 适用人群全年龄，无付费、无社交、无用户生成内容

本政策说明《一塌到底》在 Android 设备上运行时，如何处理（以及不处理）与你有关的信息。

二、收集哪些个人信息 —— 一项都不收集

本应用不收集任何个人信息，包括但不限于：

信息类型是否收集说明
手机号 / 邮箱 / 账号不收集无需注册、无需登录
位置（GPS / 基站 / IP 归属地）不收集不申请定位权限，也不做 IP 归属地识别
设备标识符（IMEI / OAID / Android ID / MAC）不收集不读取、不上报
通讯录 / 短信 / 通话记录不收集不申请相关权限
相册 / 摄像头 / 麦克风不收集不申请相关权限
剪贴板 / 已安装应用列表不收集不读取
网络与流量信息不收集不申请网络权限，应用全程离线
崩溃 / 埋点 / 行为统计不收集未接入任何统计或崩溃上报 SDK

三、申请的系统权限 —— 零项

本应用在 AndroidManifest.xml 中未声明任何权限，包括网络权限（INTERNET）。因此应用在技术上不具备联网能力，也无法读取设备上与你有关的任何数据。

游戏内的音效由 Web Audio 在本地实时合成，不需要音频采集权限。

四、游戏数据存在哪里

你产生的数据只有一类：本机游戏进度。包括最深层数、累计塌掉块数、预览券数量、砖墙点亮格数、今日砖报进度、新手引导是否看过。

  • 存储位置：本机应用私有目录内的 WebView 本地存储（localStorage），仅本应用可读写；
  • 是否上传：不上传。应用没有网络权限，这些数据不存在被发送到服务器的技术路径；
  • 是否共享：不共享给任何第三方；
  • 如何删除：卸载应用即随应用私有目录一并删除；也可在系统"设置 → 应用 → 一塌到底 → 存储"中清除数据；
  • 换设备：不同步，新设备从零开始（因为没有账号体系）。

五、第三方 SDK —— 无

当前版本未集成任何第三方 SDK：无广告 SDK、无统计 SDK、无推送 SDK、无登录/支付 SDK、无崩溃上报 SDK、无热更新框架。

说明：本作曾规划接入 TapADN（Dirichlet）激励视频广告；该能力在本版本中已完全移除（无广告代码、无广告 SDK、无相关权限）。若未来版本重新接入广告，本政策会在发布前更新，并在游戏内首次启动时以显著方式提示与征得同意。

六、未成年人保护

本游戏为单机益智类，无付费、无广告、无社交、无用户生成内容，不含任何可能诱导消费的设计。由于不收集任何个人信息，也就不存在对未成年人个人信息的收集与使用。

若你是未成年人，建议在监护人指导下使用；监护人如对本文档有疑问，可通过下方联系方式与我们联系。

七、你的权利

由于我们不持有你的任何数据，因此不存在"查询、更正、导出、撤回同意"等待处理的数据。删除数据的唯一入口在你自己的设备上：

  1. 卸载应用 —— 数据随应用私有目录删除；
  2. 系统设置中清除本应用数据 —— 立即生效，游戏进度归零。

八、政策更新

若功能发生变化（例如未来接入广告或统计服务），本政策会在版本发布前更新，并在游戏内以页面或弹窗形式提示。更新后的政策自页面标注的生效日期起适用。

九、联系我们

对本政策有任何疑问、意见或投诉，可通过以下方式联系开发者：

  • 渠道一：在 TapTap《一塌到底》游戏页的开发者主页 / 评论区留言（推荐，我们会定期查看）；
  • 渠道二：在本仓库提交 Issue（GitHub Issues）。

我们会在收到后 15 个工作日内回复。
